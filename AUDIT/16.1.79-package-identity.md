## Scope

This candidate is based on the current 16.1.78 source tree and keeps the project’s cumulative ERP functions. The focused payroll improvements are:

- The HR & Payroll workspace uses collapsed employee/payroll setup panels; the month key, first day and last day prefill the current full calendar month and remain editable.
- A permission-checked read-only `GET /stockland/v16/hr/payroll/{id}` route returns the selected period and its detail lines for review.
- Management can inspect employee-level base, gross, taxable income, PAYE, employee/employer pension, other deductions, net pay, rule version and allowance components before submission.
- Only DRAFT lines can be recalculated. The existing statutory calculation service is reused; no payroll formula, rate, tax-rule version or effective date is changed.
- Server submission is blocked if any line is uncalculated or not on the current statutory rule version. Owner approval still requires independent authorized approval, a balanced journal and required exemption evidence; payment remains a separate Owner action.
- Saved, verified exemption components are preserved when another draft amount changes. Invalid saved exemption evidence returns a controlled conflict instead of an unhandled exception.
- Retainer/service contracts remain excluded from employee PAYE/pension payroll as configured; the UI retains the existing exclusion warning.
