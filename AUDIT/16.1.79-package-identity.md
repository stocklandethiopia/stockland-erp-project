## Scope

This candidate reduces manual data entry and adds a review-first UI to the current payroll REST workflow.

- One month picker derives the `YYYY-MM` period key, first date and last date for the selected calendar month.
- After draft generation, the UI opens a responsive, line-by-line payroll review with real server-returned values and calculation status.
- Management can edit only DRAFT lines through the existing REST endpoint. Server recalculates statutory values and records the audit event in the transaction. Legacy/current-rule mismatches must be recalculated before submission.
- Management submits the reviewed draft. The active Owner independently reviews and approves/post the balanced general-ledger journal. The Owner separately records bank or cash payment, with explicit confirmation. The UI does not expose one-click approval/payment from the summary row.
- A previously calculated, current-rule pensionable-salary classification is reused only when the value remains identical. New, legacy, stale-rule or changed non-standard pensionable salary still requires the existing legal/contract rationale.
- No new payroll endpoint, payroll table, schema migration, business-data rewrite or historical payroll recalculation is introduced.
